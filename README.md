# КОНТУР ГЛАВНОЕ — корпоративный сайт

Сайт-визитка рекламного агентства полного цикла: главная страница и отдельная
страница политики конфиденциальности (`/privacy`).

Стек: React, TypeScript, Vite, обычный CSS. Сторонних скриптов, трекеров и
библиотек анимации нет; шрифт Inter лежит в проекте и не загружается с чужих серверов.

## Установка

Нужен Node.js 20.19 или новее (подойдёт 22).

```bash
npm install
```

После первой установки закоммитьте появившийся `package-lock.json` — так сборка
на Vercel будет использовать те же версии пакетов.

## Локальная разработка

```bash
cp .env.example .env.local   # необязательно: нужно только для формы
npm run dev
```

Сайт откроется на `http://localhost:5173`.

## Производственная сборка

```bash
npm run typecheck   # проверка типов TypeScript
npm run build       # сборка в папку dist
npm run preview     # локальный просмотр собранного сайта
```

## Контактные данные

Все контакты хранятся в одном файле: `src/config/contacts.ts`.

```ts
export const contacts = {
  phone: '',                               // '+7 900 000-00-00'
  max: '',                                 // полная ссылка
  vk: '',                                  // полная ссылка
  telegram: 'https://t.me/konturglavnoe',
  email: '',                               // 'hello@example.ru'
};
```

- Пустая строка означает «контакт не указан». Такой пункт не выводится ни в
  разделе «Контакты», ни в подвале, поэтому пустых ссылок на сайте нет.
- Телефон автоматически получает ссылку `tel:`, почта — `mailto:`.
- MAX, ВКонтакте и Telegram открываются в новой вкладке.

Сейчас заполнен только Telegram. Телефон, MAX, ВКонтакте и почту нужно вписать.

## Форма обратной связи

Форма отправляет сообщения через [Formspree](https://formspree.io).

1. Зарегистрируйтесь на formspree.io и создайте форму.
2. Скопируйте её адрес вида `https://formspree.io/f/xxxxxxxx`.
3. Укажите его в переменной `VITE_FORMSPREE_ENDPOINT`:
   - локально — в файле `.env.local`;
   - на Vercel — в Settings → Environment Variables.
4. Пересоберите сайт (на Vercel — Redeploy): переменная подставляется при сборке.

Пока переменная не задана, кнопка отправки отключена, а над формой написано, что
она не подключена. Сообщение об успешной отправке показывается только после
подтверждения от Formspree; при ошибке сервера или сети посетитель видит ошибку.

Адрес формы Formspree не является секретом: он виден в коде любой страницы с
формой. Приватные ключи в проекте не используются. Файлы `.env*` в репозиторий
не попадают.

## Политика конфиденциальности

Текст находится в `src/pages/Privacy.tsx`. Это базовый шаблон: поля в квадратных
скобках (наименование организации, ИНН, ОГРН, адрес, почта, дата, сведения о
сервисе обработки форм) нужно заполнить, текст — согласовать с юристом, после
чего убрать блок-предупреждение `privacy__note` в начале страницы.

## Логотип

- `public/assets/logo.png` — логотип на прозрачном фоне, 1600 px по ширине;
- `public/assets/logo-480.png` — уменьшенная версия для шапки и подвала;
- `public/assets/og.png` — картинка для соцсетей;
- `public/favicon*.png`, `favicon.ico`, `apple-touch-icon.png` — значки из контура логотипа.

Файлы получены из присланного изображения 640×640: логотип обрезан по краям и
отделён от фона, форма и пропорции не менялись. Если есть исходник в векторе
(SVG, AI, PDF) или в большем размере, замените им `logo.png` и `logo-480.png` с
теми же именами — на крупных экранах логотип станет ещё чётче.

## Публикация на Vercel

1. Откройте [vercel.com/new](https://vercel.com/new) и импортируйте этот репозиторий.
2. Vercel сам определит Vite. Настройки по умолчанию подходят:
   Build Command — `npm run build`, Output Directory — `dist`.
3. В Environment Variables добавьте `VITE_FORMSPREE_ENDPOINT`.
4. Нажмите Deploy.

Файл `vercel.json` направляет все адреса на `index.html`, поэтому страница
`/privacy` открывается и по прямой ссылке, и после обновления.

### Адрес сайта, sitemap.xml и robots.txt

`robots.txt` и `sitemap.xml` создаются при сборке. Для карты сайта нужен адрес:

- на Vercel он берётся автоматически из адреса проекта;
- после подключения собственного домена задайте `VITE_SITE_URL`
  (например, `https://example.ru`, без слэша в конце) и пересоберите сайт.

Если адрес неизвестен (обычная локальная сборка), `sitemap.xml` не создаётся,
чтобы в нём не оказался выдуманный домен.
